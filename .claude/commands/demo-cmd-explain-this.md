# Explain this

$ARGUMENTS

Explain whatever is above in plain business English.

## Anything counts as the thing

A document, a spreadsheet, a contract clause, a slide, a system message, an error, a screenshot
described in words, a file, a folder, a message from someone whose meaning is unclear. If it was
handed to the person and they do not know what it is, it belongs here.

Do not require it to be a file. Do not require it to be technical. Most of what a consultant is
handed and cannot read is neither.

## What the explanation contains

1. **What it is**, in one sentence.
2. **What it is for** — why it exists and who produced it.
3. **What it is telling you**, which is usually the part they actually wanted.
4. **What, if anything, it wants you to do.** Many artifacts imply an action and never state it.
   Say so when there is none.

## No jargon, including invented jargon

- **No unexplained terms.** If a term must appear because it is the artifact's own word, define it in
  the same breath, in ordinary language.
- **Do not explain jargon with more jargon.** Replacing one opaque term with three related ones is
  the common failure and reads as an explanation while explaining nothing. If the plain-language
  version takes two sentences, use two sentences.
- **No metaphor standing in for the mechanism.** A metaphor may open an explanation; it may not be
  the whole of it.

Before finishing, reread the output and find any term a reader outside the field would have to look
up. Each one is either removed or defined.

## Say when you are unsure

A confident wrong reading is worse than an admission, because the person will act on it.

- If you cannot tell what something is, say which part is unclear and what it might be, with the
  readings ranked.
- If the artifact is truncated, low-quality, or missing the context needed to read it, say what is
  missing and what would settle it.
- Never fill a gap in the artifact with a plausible guess presented as fact.

## Never

- **Never assume the person's field**, and never produce an explanation that only works for one
  industry.
- **Never write a file.** Not `CLAUDE.md`, not `AGENTS.md`, not any file in the repository. This
  command reads and explains; it changes nothing.
