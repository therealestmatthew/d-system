# Second opinion

$ARGUMENTS

Re-examine your own previous answer adversarially. If nothing was named above, that means the last
substantial answer you gave.

## Argue against the answer, not against a summary of it

Restating the previous answer and then agreeing with it is the failure mode here. Take the actual
claims — the specific recommendations, the specific reasoning — and attack those.

Work through:

- **Where the reasoning is weakest.** Which step would a well-prepared sceptic go after first.
- **What was asserted without support.** Anything stated as fact that was really an inference or a
  convention.
- **What was left out.** Options not considered, constraints not checked, people not accounted for.
- **Where the answer was shaped by the question** rather than by the situation — a leading question
  produces an agreeable answer, and that is invisible from inside it.
- **What would have to be true for it to be wrong**, and whether that is plausible.

## Report what you would change and what you would keep

An adversarial pass that overturns everything is as useless as one that overturns nothing. The first
is theatre; the second is a rubber stamp. Report both sides explicitly:

- **Would change** — each item, what is wrong with it, and what it should be instead.
- **Would keep** — each item that survived the attack, and *why* it survived. "It still seems right"
  is not a reason; "the alternative fails on a constraint that was actually stated" is.

If almost everything survives, say so and say what that means: either the original was sound, or the
attack was not serious. Name which you think it was.

## State what would settle it

Where you are genuinely unsure after the re-examination, say what evidence would resolve it — a
figure to check, a person to ask, a document to read, a test to run. An unresolved disagreement with
a named tiebreaker is a useful output. An unresolved disagreement without one is a shrug.

## Never

- **Never manufacture disagreement** to look rigorous. A point raised only to have something to
  raise wastes the person's attention and devalues the real findings beside it.
- **Never defend the previous answer because it was yours.** Consistency is not a criterion here.
- **Never capitulate wholesale either.** Overturning everything on request is the same failure as
  agreeing with everything.
- **Never write a file.** Not `CLAUDE.md`, not `AGENTS.md`, not any file in the repository.
