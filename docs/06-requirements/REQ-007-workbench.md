# Workbench requirements

## Observed problem and scope

The owner reviewed the integrated demo stage on 2026-09-10 and decided it becomes the chartered
management UI (`PROMPT-020`): a configurable workbench of panels, layouts and injection controls,
presented at the live demo the week of 2026-09-15. The demo stage (REQ-006 rows R01–R05 and
R10–R12) is the foundation; this requirement covers what changes and what is added — the notes
strip, the terminal panel rework and new injection sources, the layout engine, the HTML Viewer,
the explorer panels, interchangeable shells, the workbench read/action API feeding them, and the
rehearsal refresh that re-times the live segment against the final UI.

Out of scope: deployment and authentication (the workbench runs loopback-only on the owner's
machines per the workbench capability decisions), editing repository data from the UI (every
route is read-only except the reveal-in-explorer action), and the outside-the-page terminal
inject/read API (parked in idea `000087`; only its session-registry half is adopted here).

Zero-scroll (REQ-006 R02) remains binding for every layout at 1280×720, 1366×768, 1920×1080 and
1024×768; each browser-facing row below is verified by the Playwright-driven browser validator
(`demo-validator-web`) with mechanical assertions, not screenshots alone.

## Delta 2026-09-11 — terminal visibility and layout assignment

Defects surfaced by the rehearsal refresh (`phase-wb-07`) and the owner's 2026-09-10/11
review — the terminal truncation, the layout-assignment duplication, and the owner's
2026-09-11 additions: the HTML Viewer rendering blank on the Windows machine and the File
Browser's missing internal scroll — decided by the owner on 2026-09-11 and confirmed in the
hand-off session. Rows W15–W18 below extend the table above; they are verified the same way (Playwright assertions by
`demo-validator-web`, pytest for backend halves). Three earlier statements are amended:

- **W05/W06 (eligibility and the configuration surface).** Eligibility moves from the slot to
  the panel: each panel declares the set of slots it may occupy, and the layout configuration
  assigns every panel to exactly one eligible slot — a total mapping of panels to slots. The
  configuration dialog is the assignment surface only; it no longer offers per-slot
  visible-panel selects (that duplication of the slot-header dropdowns was never intended).
  Slot-header dropdowns remain pure switchers over the panels currently assigned to their slot
  and never re-assign. W06's "assigned to exactly one slot per layout" stands and now describes
  this model.
- **ADR-016 decision 1 (`admits` lists).** The per-slot `admits` list in the layout files is
  superseded by per-panel eligibility carried in the same files under a bumped
  `schema_version`. ADR-016's other rules stand unchanged; in particular rule 3 covers the
  migration — stored browser state written against the old schema is silently discarded in
  favor of the new defaults (owner decision 2026-09-11: version bump, no ADR amendment).
- **ADR-014 / REQ-006 R10 (session caps).** The backend's global concurrent-PTY cap rises from
  four to six; the per-panel session-tab cap stays four (owner decision 2026-09-11). R10's
  wording is updated to state both numbers, and ADR-014's cap wording is updated by the
  implementing phase.

## Descope ladder

Emergencies only — the owner chose all workstreams (`PROMPT-020` decision 6). Applied in order
when the week runs short; each rung is independent of the ones below it, and the rehearsal
refresh (W13) is never descoped:

1. CMD and PowerShell panels ship as message-only entries (bash only; W12 narrows to Linux).
2. The priority-queue views drop from the Idea and Backlog explorers (W10/W11 standard view only).
3. The File Browser context menu reduces to reveal-in-explorer and open-in-HTML-Viewer (W09).
4. The HTML Viewer loses tabs — one directory/search context (W08 drops, W07 stands).
5. The Idea and Backlog explorers drop; the explorer slot holds the File Browser only (W10/W11 drop).
6. Layout 2 drops — one layout ships, the engine and configuration surface stand (W05 narrows).
7. The notes-file picker drops — the strip reads the fixed current file (W01 narrows).
