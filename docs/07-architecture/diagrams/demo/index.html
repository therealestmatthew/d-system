Skills and agents — diagram library

Six standalone diagrams for the skills-and-agents training session. Each is a self-contained SVG drawn at 1024×768 with no external asset or network dependency: open this page or any single file straight from the filesystem, with no dev server running. The labels come from the glossary entries in brain/concepts/terms-skills-and-agents-demo.md.

LLM vs agent

The same model on both sides — the loop, the tools and the permissions are what differ.

Skill architecture

What a skill folder holds, and which half of SKILL.md is in the context before it is invoked.

The agentic loop

Context, model call, tool call, result appended — every pass a fresh call over a larger context.

Sub-agents and context isolation

A sub-agent works in its own context window; only its final report crosses back.

MCP architecture

The application is the MCP client; servers expose tools that land in the model's list beside the built-in ones.

Command, skill, tool

Who initiates each one — the person, or the model — with this repository's examples of all three.

Built by phase-demo-07 for REQ-006 R13. SVG rather than Mermaid because these are presented from the filesystem at a fixed projector size, which GitHub-rendered Mermaid cannot do. To change a label, edit the glossary entry first and then the diagram — the acceptance condition is that the two match exactly.
