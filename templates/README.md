# Templates

Reusable templates for HTML generation and styling.

| Directory | Purpose |
|---|---|
| `html/` | HTML page and component templates — base layouts, section blocks, composable page structures |
| `styles/` | CSS/style definitions, design tokens, theme files tied to specific HTML template families |

## Template families

| Family | Files | For |
|---|---|---|
| `overview` | `html/overview-*.html`, `styles/overview.css` | Embeddable data panels — selectors scoped under `.overview`, no JavaScript, generated by `tools/generate_overview.py` |
| `atlas` | `html/atlas-page.html`, `html/atlas-components.html`, `styles/atlas.css` | Standalone showcase / report / architecture pages — dark green-and-mahogany design system with an interactive shell (sidebar nav, collapsible sections, focusable SVG diagrams). The shell JS is part of the family and documented in `atlas-page.html`; rendered references: `_public/d-system-architecture.html`, `_public/prompt-pack-protocol.html`, `_public/research-protocol.html` |

## HTML Generation System

Templates here are consumed by the HTML Generation Framework:
- Raw source data (from `_data/` or DuckDB) feeds into templates
- Deterministic generation scripts live in `tools/` or `src/`
- React/FastAPI interface in `ts/` + `src/` drives generation, previews results, and triggers agentic workflows
- Output pages can be grouped into dynamically composable multi-page frameworks
