# Replace with the decision's title

Allocate the real code with the next-code command before this file is committed, and set both
dates. Replace every paragraph below; keep the headings. A decision record states one decision.
It moves from `draft` to `accepted` only when the owner accepts it.

## Context

The problem that forces a decision, the constraints that apply, and where the evidence for them
is.

## Decision

What was decided, in one or two sentences, then the details someone needs to apply it. Say who
decided and on what date.

## Alternatives considered

Each alternative that was rejected, and why: what it would have cost, or what it could not do.

## Consequences

What becomes easier and what becomes harder because of this decision, including the work it
creates and the decisions it rules out.

## Open questions

Each open question, who decides it and when. Write "None outstanding" when nothing is open.
