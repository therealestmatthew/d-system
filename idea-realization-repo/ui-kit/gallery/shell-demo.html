What the kit is for

The kit gives every screen the same frame: a fixed shell of named regions, and a panel in each region with exactly one header. The body of a panel scrolls; the page does not.

Layouts are data. The grid for this page comes from layouts/ide.json, compiled into dist/layouts.css. Change the file and regenerate; no component CSS changes.

Regions

  • Header: the app bar.
  • Nav: navigation, with the current item marked.
  • Main: the focal surface.
  • Inspector: properties of the current selection.
  • Dock: console, logs and runs; collapsible to its header.
  • Strip: one line of ambient status.

Density

Below 1100 by 800 everything inside the shell takes the compact density tokens, from dist/tokens.css; data-density="comfortable" on the shell or an ancestor opts out. Below 1024 wide the regions stack in one column and the page may scroll.

This paragraph and the ones above are long enough that, on a small window, the document body scrolls inside the panel while the shell stays fixed.

Every number on a generated page names its source and its time. A missing value reads "not recorded", never zero.
