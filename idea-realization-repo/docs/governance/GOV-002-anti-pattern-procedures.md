# Anti-pattern procedures

This document will hold the procedures that stop a known mistake from recurring: each names the
habit that caused a slip, the check that catches it, and what to do instead. They are how a
correction made once reaches every later session, whichever model or person is working.

**It is deliberately empty.** Each procedure enters only after the owner approves it, one at a
time, in a dedicated session. An agent that makes a mistake which could recur says so and proposes
a procedure; it does not add one here itself.
