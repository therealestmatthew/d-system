# Standing rules

This document will hold the repository's standing rules: rulings the owner has made once that
apply to every later session, such as when a review finding may be accepted rather than fixed, or
which decisions a coordinator may take without asking.

**It is deliberately empty.** Rules enter it only in a dedicated session in which the owner reviews
each one and signs it off before it is written here. An agent never adds a rule to this document
on its own reading of a conversation, and a one-time instruction is never recorded as a standing
rule.

Until rules exist here, the plugin's protocol documents (`plugins/idea-realization/docs/`) and
`CLAUDE.md` govern.
