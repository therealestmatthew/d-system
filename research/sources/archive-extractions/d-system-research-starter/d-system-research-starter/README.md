# D-System Research Starter

This repository captures the current D-System research architecture and defines a reproducible literature-review process for evaluating prior art, overlap, and novelty.

## Repository purpose

The goal is not to prove that D-System is novel. The goal is to **try to falsify the novelty claim** by finding the strongest existing systems, theories, ontologies, and implementations that already solve the same problems.

The present working thesis is that D-System may be differentiated by the synthesis of:

1. Multi-dimensional classification of knowledge states.
2. Explicit typed transitions between states.
3. Append-only reasoning/history preservation.
4. Provenance over transitions, including human, agent, group, and system actors.
5. Conflict resolution informed by authority, evidence, reliability, independence, recency, and convergence.
6. Retrieval/context transfer that uses epistemic topology and reasoning lineage, not similarity alone.

## Files

- `architecture.md` — current conceptual architecture.
- `novelty_hypotheses.md` — falsifiable claims to test.
- `literature_review_protocol.md` — research protocol.
- `agent_instructions.md` — instructions for code/research agents.
- `source_ledger.md` — sources identified so far.
- `evidence_matrix_template.csv` — structured comparison schema for papers/systems.
- `transition_vocabulary.md` — preliminary controlled vocabulary for state transitions.

## Research principle

Do not modify the architecture to match prior art during the initial literature review. Record overlap, contradiction, and gaps first. Architecture revisions should occur only after an explicit synthesis phase.
